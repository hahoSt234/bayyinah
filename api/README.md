# بيّنة: النظام

النظام اللي يستقبل المقطع من الواجهة، ويحلله، ويرجع التقرير.

## وش يسوي

1. **يقرأ المدخل:** نص، أو صوت، أو فيديو (ياخذ منه الصوت).
2. **يفرّغ الصوت نصياً** بنموذج Whisper.
3. **يدور على الأحاديث** في القاعدة المغلقة اللي جمعتها هيفاء، ويرجع الحكم بلفظه ومن حكم والمصدر والبديل الصحيح. ما فيه أي نموذج لغوي يكتب حكم من عنده.
4. **يفحص أصالة الصوت** (قيد التفعيل، نختار النموذج بعد التجربة).
5. **يقرر:** مؤيد بالمصدر، أو مخالف للمصدر، أو غير محسوم. وإذا ما لقى الحديث يمتنع، لأن غيابه من القاعدة ما يعني إنه موضوع.

ولا يحتفظ بأي مقطع بعد التحليل.

## الملفات

| الملف | وش فيه |
|---|---|
| `app.py` | الواجهة البرمجية: `/health` و `/analyze` |
| `engine.py` | محرك البحث في الأحاديث |
| `arabic.py` | تطبيع النص العربي (التشكيل والهمزات والتاء المربوطة) |
| `audio.py` | قراءة الصوت والتفريغ وفحص الأصالة |
| `verdict.py` | قواعد الحكم والامتناع |
| `build_db.py` | يبني القاعدة من ملفات هيفاء |
| `evaluate.py` | يقيس دقة النظام |
| `data/hadiths.json` | القاعدة |
| `data/review.txt` | الحالات اللي تحتاج مراجعة هيفاء |

## التشغيل على الجهاز

```
pip install -r requirements.txt
uvicorn app:app --reload --port 7860
```

وبعدين افتحي `http://localhost:7860/docs` وجربي.

## تحديث القاعدة

إذا عدلت هيفاء ملفاتها، حطيها في `data/raw` وشغلي:

```
python build_db.py data/raw/*.docx
python evaluate.py
```

## الخوارزمية باختصار

- **التطبيع:** حذف التشكيل والتطويل وعلامات الترقيم، وتوحيد الهمزات والياء والتاء المربوطة.
- **تقطيع الكلام:** الكلام الطويل يتقطع لجمل ومقاطع متداخلة، لأن الحديث يكون جزء من كلام أطول.
- **المطابقة:** تشابه على مستوى الحروف (TF-IDF من 3 إلى 5 حروف) عشان يتحمل اختلاف الإملاء، مع نسبة احتواء كلمات الحديث بنفس الترتيب.
- **حدود محافظة:** المطابقة تحت 0.55 تعتبر غير موجودة، والمقاطع القصيرة (كلمتين) تحتاج 0.8.
- **كل مقطع من الكلام ينسب لحديث واحد بس،** عشان ما يطلع حديث ثاني يشبهه بالغلط.

## حدود النسخة الحالية

- فحص التزييف مو مفعل بعد.
- المطابقة مع الدرس الأصلي تحتاج أرشيف، وما بنيناه بعد.
- التحليل من الرابط مباشرة غير متاح، فالمستخدم يكتب وش انقال في المقطع.
